# Absolute paths backed up as-is, IN ADDITION to $DATA_DIR and $ROOT_DIR
# (the latter already covers ~/.config/rclone/rclone.conf, since that's
# under /root). Restic preserves the exact path, so `restic restore
# --target /` puts every one of these back exactly where it came from —
# no manual "which file goes where" step during recovery.
#
# One absolute path per line. # comments and blank lines are fine. Missing
# paths are skipped with a note rather than failing the backup (useful
# before you've configured ssmtp/fail2ban on a given box, etc).
